# iOS App Store deploy guide

This project is wired up to ship as an iPhone app via Capacitor. The Astro
site is bundled as static web assets inside a thin native shell.

## One-time machine setup

1. **Install full Xcode** (not just Command Line Tools) from the Mac App
   Store. After install, run:
   ```bash
   sudo xcode-select -s /Applications/Xcode.app/Contents/Developer
   sudo xcodebuild -license accept
   ```
2. **Enroll in the Apple Developer Program** ($99/year)
   — https://developer.apple.com/programs/
3. **Register the bundle identifier** `com.maadhavkothari.finraprep`
   at https://developer.apple.com/account → Identifiers → "+".
   (Or change the appId in `capacitor.config.ts` before continuing.)

## Test locally in iOS Simulator

```bash
npm run ios:sync     # builds with BUILD_TARGET=ios, copies into ios/App/App/public
npm run ios:open     # opens ios/App/App.xcodeproj in Xcode
```

In Xcode:
1. Top toolbar → select an iPhone simulator (e.g. **iPhone 16 Pro**)
2. Press the ▶ Run button (or ⌘R)
3. The simulator boots and launches **FINRA Prep**

Every time you edit Astro code, re-run `npm run ios:sync` and re-run in
Xcode.

## Test on your physical iPhone

1. Plug your iPhone in via cable. Trust this computer.
2. In Xcode, select your device from the top toolbar.
3. Xcode → **Signing & Capabilities** tab → "Team" → pick your Apple ID team
   (after you've added your Apple ID under Xcode → Settings → Accounts).
4. Press ▶. Xcode will install the app on your phone.
5. First launch: iPhone → Settings → General → VPN & Device Management →
   trust your developer certificate.

## Submit to the App Store

### Pre-flight checklist
- [ ] App icon: drop a 1024×1024 PNG into
      `ios/App/App/Assets.xcassets/AppIcon.appiconset/`. Xcode 14+ auto-
      generates the rest of the sizes from a single 1024 image.
- [ ] Launch screen: edit `ios/App/App/Base.lproj/LaunchScreen.storyboard`
      in Xcode if you want it branded.
- [ ] Version & build: Xcode → App target → **General** tab → set
      Version (e.g. `1.0.0`) and Build (e.g. `1`).
- [ ] Privacy policy URL: required for App Store Connect. Host one
      (a GitHub Pages page works). The app doesn't collect data, but
      Apple still needs the URL.
- [ ] Category: Education.
- [ ] Age rating: 4+.

### Archive & upload

1. In Xcode top toolbar, change the device dropdown from a simulator to
   **Any iOS Device (arm64)**.
2. Menu: **Product → Archive**. Xcode builds a release archive.
3. When the **Organizer** window pops up, select your archive →
   **Distribute App** → **App Store Connect** → **Upload**.
4. Wait for processing (~10–30 min).

### App Store Connect listing

1. Go to https://appstoreconnect.apple.com → My Apps → **+** → New App.
2. Bundle ID: `com.maadhavkothari.finraprep`. SKU: anything (e.g.
   `finra-prep-001`).
3. Fill in:
   - **App name** (≤30 chars): `FINRA Prep`
   - **Subtitle** (≤30 chars): e.g. `SIE & Series 7/63/24 practice`
   - **Description** (≤4000 chars): mention all 9 exams, story cards,
     offline mode.
   - **Keywords** (≤100 chars, comma separated): `FINRA,SIE,Series 7,
     Series 63,Series 24,Series 6,Series 65,Series 66,securities,exam`
   - **Screenshots**: 6.7" (iPhone 16 Pro Max) and 6.5" required.
     Use **iPhone 16 Pro Max simulator** → Cmd+S to capture.
   - **Promo image** (optional)
4. Select the build you uploaded.
5. **Submit for Review**. Typical review time: 1–3 days.

## App Store rejection risks to know about

**Guideline 4.2 — Minimum Functionality.** Apple rejects apps that are
just wrappers around a website. This app is defensible because:
- All questions are bundled offline (no network required)
- Local progress tracking (XP, streaks)
- Multiple exam tracks (9 exams, hundreds of Qs)
- Interactive quiz UI with explanation cards

**Guideline 2.3.10 — Accurate Metadata.** Don't mention "Best FINRA prep
in the world" or other unverifiable claims in the App Store description.

**Guideline 5.0 — Legal.** The footer already says "not affiliated with
FINRA" — good. Keep that.

## Updating the app

1. Edit Astro code as usual.
2. Bump the build number in Xcode (Version stays the same for patches,
   Build increments).
3. `npm run ios:sync`
4. Xcode → Product → Archive → upload.
5. In App Store Connect, attach the new build and submit.

## File layout reference

```
capacitor.config.ts          # appId, appName, splash, status bar
ios/App/App.xcodeproj        # Xcode project — open this
ios/App/App/public/          # Synced web assets (gitignored; regenerated by ios:sync)
ios/App/App/Assets.xcassets/ # App icon, accent color
ios/App/App/Info.plist       # Native plist (set display name, etc.)
```

## Bundle ID change

If `com.maadhavkothari.finraprep` is taken or you want a different one:

1. Edit `appId` in `capacitor.config.ts`
2. Delete `ios/` folder
3. `npx cap add ios`
4. Re-do signing in Xcode.
