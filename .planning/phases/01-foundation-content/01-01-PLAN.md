  <action>
    1. Run `npm create astro@latest -- --template minimal --typescript strict --no-install` in the project root (or create the files manually if the CLI is interactive). The project root IS the repo root `/Users/mkothari/projects/finra-sie-exam/`.

    2. Edit `package.json` to add the Vite override BEFORE installing dependencies:
       ```json
       "overrides": {
         "vite": "^7"
       }
       ```
       This prevents npm from hoisting Vite 8 which breaks @tailwindcss/vite (per GitHub issue withastro/astro#16542).

    3. Install dependencies:
       ```bash
       npm install tailwindcss @tailwindcss/vite @tailwindcss/typography
       npm install -D @astrojs/check
       ```
       Do NOT install zod separately -- Astro 6 bundles Zod v4 via `astro/zod`.

    4. Configure `astro.config.mjs`:
       ```javascript
       import { defineConfig } from 'astro/config';
       import tailwindcss from '@tailwindcss/vite';

       export default defineConfig({
         site: 'https://mkothari.github.io',
         base: '/finra-sie-exam',
         vite: {
           plugins: [tailwindcss()],
         },
       });
       ```
       Note: The `site` value uses the GitHub username. The `base` path matches the deploy repo name for correct asset paths on GitHub Pages.

    5. Ensure `tsconfig.json` has `"extends": "astro/tsconfigs/strict"` (Astro's minimal template sets this).

    6. Verify build works: `npm run build` should complete without errors and produce a `dist/` directory.
  </action>
  <verify>
    <automated>cd /Users/mkothari/projects/finra-sie-exam && npm run build 2>&1 | tail -5</automated>
  </verify>
